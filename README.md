# Invitación de Valeria

Sitio estático listo para Vercel. El sitio publicado necesita `index.html`, los cinco archivos WebP de `assets/` y `1660 . DISCO INFERNO - THE TRAMPS.mp3`. La música comienza en la segunda escena y se puede silenciar desde la invitación. No requiere Node.js, instalación de dependencias ni proceso de compilación.

## Publicar desde GitHub

1. Sube a un repositorio los archivos que no estén excluidos por `.gitignore`.
2. En Vercel, importa ese repositorio.
3. Usa la raíz del repositorio como **Root Directory**. `vercel.json` selecciona **Other**, omite la compilación y sirve la raíz.
4. Despliega y comprueba la portada, la apertura del sobre y las seis escenas.

Las copias `invitacion-version-*.html` son respaldos locales y no forman parte del sitio publicado.
