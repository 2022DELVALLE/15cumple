# Invitación de Valeria

Sitio estático listo para Vercel. El sitio publicado necesita `index.html`, los cinco archivos WebP de `assets/`, las cuatro piezas `assets/intro-*` y `musica de fondo.mp4`. La música comienza al abrir el sobre y se puede silenciar desde la invitación. La séptima escena muestra una cuenta regresiva al 20 de noviembre de 2026 a las 7:00 p. m. (hora de Perú). El enlace de Google Maps busca el nombre del local; se debe sustituir por su ubicación exacta cuando esté confirmada. No requiere Node.js, instalación de dependencias ni proceso de compilación.

## Publicar desde GitHub

1. Sube a un repositorio los archivos que no estén excluidos por `.gitignore`.
2. En Vercel, importa ese repositorio.
3. Usa la raíz del repositorio como **Root Directory**. `vercel.json` selecciona **Other**, omite la compilación y sirve la raíz.
4. Despliega y comprueba la portada, la apertura del sobre y las siete escenas.

Las copias `invitacion-version-*.html` son respaldos locales y no forman parte del sitio publicado.
